# Отчёт о проекте Mi Unlock

## Цель

Перенести функциональность Python-скрипта MiCommunityTool в автономное Android-приложение с MVI, точным планированием по GMT+8, работой в фоне и визуальным стилем Xiaomi/карандаш.

## Разобранная логика оригинала

1. Получить `new_bbs_serviceToken` и `deviceId`.
2. Проверить `/bbs/api/global/user/bl-switch/state`.
3. Синхронизировать часы по NTP Aliyun.
4. Вычислить следующую полночь Asia/Shanghai минус заданная задержка.
5. За 10 секунд прогреть HTTPS-сессию.
6. В точный момент отправить POST `/bbs/api/global/apply/bl-auth` с `{"is_retry":true}`.
7. Расшифровать `apply_result` и серверное время `ts`.

## Реализация

- **Presentation:** Compose + `MainViewModel`, intents и immutable state.
- **Auth:** прямой Xiaomi Passport/Mi Community вход через Compose и QR; доступны телефон, email, Xiaomi ID и QR. Для 2FA код отправляется на email, если Xiaomi его предлагает, иначе по SMS; итоговая BBS-сессия извлекается автоматически.
- **Data:** OkHttp, DataStore, собственный минимальный SNTP-клиент; опциональный HTTP-прокси для проверок и заявки.
- **Background:** foreground service `dataSync`, WakeLock, START_STICKY.
- **Reliability:** монотонные часы `elapsedRealtimeNanos`, NTP reference point, до шести сетевых попыток, прогрев соединения; проверка измеряет HTTPS RTT и подбирает консервативное смещение; автоматическая контрольная проверка статуса после подачи заявки выявляет выдачу разрешения в БД Xiaomi даже при возврате API-ошибок лимита.
- **Time:** `ZoneId.systemDefault()` для локального времени и `Asia/Shanghai` для Пекина.
- **UX:** живые часы, статус-фазы, countdown в уведомлении, проверка аккаунта, опережение, автозапуск, инструкция по battery optimization.
- **Security:** приложение получает пароль и одноразовые коды через собственные Compose-поля и Python-авторизацию, но не сохраняет их; сессия и при необходимости данные прокси сохраняются в sandbox приложения. Cleartext traffic и backup выключены.

## Статусы API

Поддержаны: доступ уже выдан, можно подать заявку, аккаунт моложе 30 дней, временная блокировка, квота исчерпана, успех, повтор через минуту, повтор позже и базовые API error codes.

## Ограничения

Android не гарантирует микросекундную точность из-за планировщика ОС и сети. WakeLock, foreground service, NTP и активное ожидание на последней секунде уменьшают отклонение. На MIUI/HyperOS необходимо вручную включить «Без ограничений» и Автозапуск.

В версии 2.0 ручной импорт больше не является основным входом. Официальная страница Xiaomi сама обрабатывает доступные для аккаунта способы авторизации, CAPTCHA и 2FA. После успешного перехода в Mi Community приложение автоматически получает `new_bbs_serviceToken`. Ручной импорт сохранён только как аварийный вариант.
