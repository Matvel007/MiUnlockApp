# Changelog

## 1.2

- Автоматическая контрольная проверка статуса после подачи заявки: выявление выданных разрешений при серверных ошибках лимита Xiaomi (Race Condition).
- Кнопка «Проверить» теперь чётко определяет и показывает наличие или отсутствие разрешения на разблокировку в аккаунте.
- Обновлены уведомления и консоль отладки для точного отображения статуса разрешения.

## 1.1

- Исправлена системная Back-навигация: консоль, настройки и QR-вход возвращают к предыдущему экрану приложения.
- Проверка аккаунта измеряет время ответа Xiaomi API и автоматически устанавливает рекомендуемое смещение перед подачей.
- Добавлен HTTP-прокси с проверкой подключения; при включении через него маршрутизируются проверки и отправка заявки.
- Для обычного входа код Xiaomi автоматически отправляется на email, если он доступен, иначе по SMS; приложение показывает выбранный канал.
- Пароль и одноразовый код больше не сохраняются при пересоздании окна входа.

## 2.0.0

- Добавлена полноценная авторизация через официальный Xiaomi Account / Mi Community.
- Поддерживаются способы, которые предлагает Xiaomi: телефон, email, Xiaomi ID и QR.
- CAPTCHA и проверка безопасности выполняются на стороне Xiaomi; 2FA-код вводится в приложении.
- `new_bbs_serviceToken` и `deviceId` извлекаются автоматически после успешного входа.
- Добавлена очистка сессии и смена аккаунта.
- Ручной импорт Cookie оставлен резервным способом.
- Пароль и одноразовые коды вводятся в приложении только для входа и не сохраняются.

## 1.0.0

- Первый Android-порт MiCommunityTool.
- MVI, Compose UI, NTP, foreground service, WakeLock и уведомления.
